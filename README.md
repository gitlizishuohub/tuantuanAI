# 答辩风洞

面向理工科本科课程项目与毕业设计的 Windows 文字答辩训练软件。导入材料，核对研究画像，接受方法、证据、应用三个视角的提问，结束后查看有出处的复盘，并从问题卡片启动专项复练。

当前版本为 **0.1.0 开发预览**。工程实现和实际验收状态见 [实施进度与验收记录](docs/验收记录.md)。原始[详细实施计划](答辩风洞-详细实施计划与评估稿.md)保留为规划依据，其中的质量指标不是已经取得的成绩。

## 首次体验

1. 安装已提供的 Windows x64 安装程序后，从桌面或开始菜单打开“答辩风洞”。源码运行方法见[开发构建说明](docs/开发构建.md)。已提供[0.1.0 Windows x64 安装包](release/答辩风洞%20Setup%200.1.0.exe)（约125.77 MiB，未签名预览版）；校验值和实际验证范围见验收记录。
2. 点击“体验示例项目”，或选择两张自编案例卡片之一。示例是虚构教学材料，数字不代表真实实验。
3. 在准备室生成研究画像，点击出处核对原文；修正六类信息后确认画像。
4. 选择正式模拟或教练陪练、10/12/15 分钟，开始训练。正式模拟结束后集中反馈；教练陪练可逐层查看提示、重答或继续下一题。
5. 提交回答，也可跳过、承认不知道或主动结束。复盘室显示五维覆盖、问题卡片、出处和行动清单。点击问题卡片的专项复练入口，换角度再练；可将报告导出为 Markdown。
6. 在训练档案重新打开已提交记录；在“设置与数据”导出备份或恢复为新增项目副本。

默认使用 **离线规则演练**，可免密钥体验流程。它使用明确规则生成问题和反馈，不构成 AI 理解、事实核查或研究质量评价。其内容正确性仍需自己核对。自己的文字材料在离线模式下需按“研究问题：”“研究目标：”“方法路线：”“核心主张：”“支持证据：”“适用边界：”显式标签填写，标签之间空行分段；没有标签的字段会显示未找到。

## 使用自己的材料与 AI

新建研究项目后可粘贴文字或导入文本型 PDF：单文件不超过 20 MB、100 页；每项目最多 3 份材料、合计 150 页；粘贴文字每次最多 30,000 字符。PDF 引用使用文件实际页序，不是论文印刷页码。扫描件、图片及复杂图表不支持 OCR 或内容理解，文字不足时请改为粘贴文字。

在“设置与数据”切换 AI 联网模式，填写服务商提供的 HTTPS OpenAI 兼容接口基础地址（到 `/v1` 等服务商规定路径，不追加 `/chat/completions`）、模型名和个人 API Key，保存并测试连接。接口需支持 Chat Completions 和 JSON 对象输出。软件不附共享付费密钥；模型调用费用由该服务商按其规则收取，尚无真实成本或延迟承诺。

联网生成画像、提问、分析和提示时，相关材料片段、必要画像与问答会发送到你配置的模型服务。请阅读界面提示并确认后使用。失败后按错误提示重试；已提交内容可从档案继续查看。模型输出引用经过 ID/摘录匹配检查，但“引用存在”不能证明推理正确，请人工复核。

## 本地数据、备份与删除

材料副本、解析文字、画像和训练保存在当前系统账户的应用数据目录；点击设置中的数据目录入口可查看实际位置。密钥通过 Electron `safeStorage` 加密保存，加密不可用时拒绝保存密钥。不要将整个数据目录作为公开交付材料。

应用备份为 JSON，包含研究材料与历史记录，不含模型密钥；恢复为新增项目副本，保留现有项目，并自动创建恢复前安全副本。备份可能包含敏感研究内容，请自行妥善保管。

删除项目将删除应用管理的项目记录与材料副本，不删除原始 PDF、另存报告及已导出的备份。卸载默认保留用户数据。需要彻底清理时先记下设置中的数据目录并按需备份，退出软件后再删除该目录。恢复前安全副本和外部备份也需单独清理。同一系统账户下多人共用电脑不提供用户隔离。

已有材料、历史问答与报告可以离线查看和导出；真实 AI 生成功能需要网络和可用模型配置。
