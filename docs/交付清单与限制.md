## 已知限制

1. 仅 Windows x64 为首发目标，未证明干净 Windows 10/11 的完整兼容性；没有 macOS/Linux 交付。
2. PDF 只提取文字，不支持 OCR、图片/复杂图表理解或 PPTX 直接导入。复杂多栏材料可能错序，须查看来源核对。
3. 离线模式使用显式规则。短回答、关键词和数字检查仅用于演练流程，不评价真实研究质量。联网模式使用用户指定的 OpenAI 兼容 Chat Completions 服务，兼容性并非覆盖所有服务商。
4. 引用校验检查存在性和原文连续摘录，不能自动保证语义支撑。疑似矛盾按待澄清处理，没有完整事实验证或学术真实性判定。
5. 报告由逐轮分析汇总，五维覆盖不等于能力评分。行动类型与完成标准较粗，需人工补充。勾选任务不会证明研究问题已解决。
6. 真实模型可能语义重复、遗漏弱点或给出泛化建议。尚未取得计划中的质量、延迟和费用成绩。
7. 本地数据不等于完全不出电脑：联网时相关研究内容与问答发送给配置的服务。服务方保留规则需自行确认。软件没有云同步、多用户账号或组织管理。
8. 备份包含材料与训练历史，JSON未额外加密。删除项目不会撤销服务商已接收内容，也不会删除用户原件、外部报告、备份和恢复前安全副本。
9. 没有自动更新、语音、多人协作或真实成绩预测。本次预览包通过 `signAndEditExecutable=false` 跳过可执行文件资源编辑及代码签名，保留默认Electron图标和部分文件元数据；未取得SmartScreen免提示或完整第三方许可合规结论。
